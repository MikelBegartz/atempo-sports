# Instrucciones

**AtempoSports** — app de horarios de club.

Cuando digas **«actualiza las instrucciones»**:

| Fichero | Uso |
|---------|-----|
| `.cursor/rules/*.mdc` (aquí y/o monorepo `../.cursor/rules/`) | Normas del agente |
| `PRODUCT.md` | Mapa de producto / roadmap / **beta tancada** |
| `docs/BETA_OPS.md` | Domini, HTTPS, SMTP, backup (paraules senzilles) |

Workspace preferit per aquest producte: carpeta **AtempoSports** (projecte independent).

**Beta tancada:** checklist tècnic a `PRODUCT.md`; ops teves a `docs/BETA_OPS.md`.
